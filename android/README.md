# تطبيق جرد الصيدلية لأندرويد

نفس واجهة الموقع لكن داخل تطبيق، والملفات كلها محلية في التطبيق (Firebase وقارئ الباركود)،
فلا يحتاج موقع github.io ولا unpkg ولا gstatic؛ يتصل فقط بخوادم Firebase من Google.

- يُبنى تلقائياً في GitHub Actions عند كل تعديل على `index.html` أو `boot.js` أو `fbsdk.js` أو `config.js` أو مجلد `android/`.
- آخر نسخة دائماً: Releases ← `jard.apk`.
- كل نسخة جديدة رقمها أعلى، فتُثبَّت فوق القديمة مباشرة دون حذف ودون فقد الدخول.
- مفتاح التوقيع `jard-release.p12` موجود هنا ليبقى التوقيع ثابتاً بين النسخ. المستودع عام، لذلك:
  لا تثبّت أي نسخة من التطبيق إلا التي يرسلها المشرف.
- الكاميرا تفتح تطبيق الكاميرا لالتقاط صورة الباركود، والتصدير يحفظ الملف في «التنزيلات/Jard» ويفتح قائمة الإرسال (واتساب…).
- في شاشة الدخول زر «فحص الاتصال بالخادم» يبيّن هل خوادم Firebase مفتوحة على شبكة الجهاز.
