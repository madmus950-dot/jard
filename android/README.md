# تطبيقات الصيدلية لأندرويد

غلاف واحد (WebView) يبني تطبيقين، والملفات كلها داخل التطبيق فلا يحتاج github.io ولا unpkg ولا gstatic:

| التطبيق | المصدر | الملف في Releases |
|---|---|---|
| جرد الصيدلية | `index.html` و`boot.js` و`fbsdk.js` | `jard.apk` |
| حسابات الصيدلية | مجلد `pharmacy/` | `pharmacy.apk` |

- يُبنيان تلقائياً في GitHub Actions عند كل تعديل، وتُنشر النسخة في Releases.
- كل نسخة رقمها أعلى من السابقة، فتُثبَّت فوقها مباشرة دون حذف ودون فقد الدخول.
- مفتاح التوقيع `jard-release.p12` هنا ليبقى التوقيع ثابتاً بين النسخ. المستودع عام، لذلك لا تثبّت إلا ما يرسله المشرف.
- قواعد Firestore للتطبيقين في `firestore.rules` بجذر المستودع.
